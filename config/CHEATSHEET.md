# Neovim 键位速查

先运行 `:Tutor`，跟着内置教程练习。键位里的 `<Space>` 指空格键。所有 `<Space>` 快捷键都在普通模式使用：先按 `Esc`，再按空格和后续字母。
停顿在 `<Space>`、`g`、`z`、`Ctrl-w` 后会出现下一步提示。用 `:Keys` 再打开本页。

## Vim 原生键：先记住这 12 个

| 键位 | 作用 |
| --- | --- |
| `Esc` | 回到普通模式 |
| `h j k l` | 左、下、上、右 |
| `w` / `b` | 下一个 / 上一个词 |
| `0` / `$` | 行首 / 行尾 |
| `gg` / `G` | 文件开头 / 结尾 |
| `i` / `a` | 在光标前 / 后插入 |
| `o` / `O` | 下方 / 上方新开一行 |
| `x` / `dd` | 删除字符 / 整行 |
| `u` / `Ctrl-r` | 撤销 / 重做 |
| `yy` / `p` | 复制一行 / 粘贴 |
| `/词`、`n`、`N` | 搜索；下一个 / 上一个结果 |
| `:w` / `:q` / `:wq` | 保存 / 退出 / 保存并退出 |

## Vim 原生键：用键位组合编辑

`动作 + 范围`。例如 `dw` 删除到下个词，`ciw` 改写当前词，`di(` 删除括号内内容，`yap` 复制整个段落。数字可以重复动作：`3j` 下移三行，`2dd` 删除两行。`.` 重复上一次修改。

| 键位 | 作用 |
| --- | --- |
| `v` / `V` / `Ctrl-v` | 字符 / 整行 / 块选择 |
| `d` / `c` / `y` | 删除 / 修改 / 复制选中范围 |
| `>` / `<` | 选中后缩进 / 反缩进 |
| `*` | 搜索光标下的词 |
| `%` | 在匹配括号间跳转 |
| `Ctrl-o` / `Ctrl-i` | 跳转历史后退 / 前进 |
| `Ctrl-x Ctrl-o` | 插入模式下请求 LSP 补全 |
| `Ctrl-n` / `Ctrl-p` | 插入模式下补全下 / 上一个词 |

## 文件和窗口

`<Space>` 前缀来自这套配置；主要入口和 LazyVim 保持一致。冒号命令和 `Ctrl-w` 是 Vim 原生用法。

| 键位 | 作用 |
| --- | --- |
| `<Space>ff` | 按文件名模糊搜索 |
| `<Space><Space>` | 也是按文件名查找 |
| `<Space>sg` / `<Space>/` | 在项目中搜索内容（需要 `rg`） |
| `<Space>fb` | 切换已打开文件 |
| `<Space>sh` | 查帮助文档 |
| `<Space>e` | 打开或关闭项目文件浏览器 |
| `<Space>ft` / `Ctrl-/` | 打开或收起项目终端 |
| `<Space>tT` | 在下方终端运行项目测试 |
| `:Root` | 切换到项目根目录 |
| `:e 路径` | 打开文件 |
| `:sp` / `:vsp` | 水平 / 垂直分屏 |
| `Ctrl-w h/j/k/l` | 切换到相邻窗口 |
| `:bd` | 关闭当前缓冲区 |

文件搜索窗口用 `Ctrl-n` / `Ctrl-p` 选择，回车打开，`Ctrl-v` 垂直分屏打开，`Esc` 退出。

`<Space>e` 会从项目根目录打开浮动文件浏览器，逐级浏览目录；模糊搜索文件名用 `<Space>ff`。浏览器里用 `j` / `k` 选文件，`l` 进入目录或打开文件，`h` 返回上级；`L` 打开文件后关掉浏览器，`q` 或再次按 `<Space>e` 关闭。按 `g?` 查看完整操作说明。浏览器里按 `i` 会进入插入模式来编辑文件名；误按时先 `Esc`，再按 `u` 撤销。只有按 `=` 并确认后，文件名修改才会写入磁盘。

终端里按 `Ctrl-\\`、`Ctrl-n` 回到普通模式，然后可用 `Ctrl-w h/j/k/l` 在窗口间切换。终端分屏可用 `<Space>ft` 收起，之后再按一次恢复。部分终端不会发送 `Ctrl-/`，这时用 `<Space>ft`。

## 代码导航（需要对应语言服务器）

| 键位 | 作用 |
| --- | --- |
| `gd` | 跳到定义 |
| `gr` | 查找引用 |
| `K` | 查看说明 |
| `<Space>cr` | 重命名符号 |
| `<Space>ca` | 代码操作 |
| `<Space>cf` | 格式化当前文件 |
| `[d` / `]d` | 上一个 / 下一个诊断 |
| `<Space>cd` | 查看当前诊断 |

`:TinyHealth` 检查 `rg` 与语言服务器。`:checkhealth vim.lsp` 查看 LSP 连接情况。

测试窗口里按 `Ctrl-\\` 后按 `Ctrl-n` 回到普通模式，再用 `Ctrl-w` 切回代码。`<Space>tT` 根据文件类型运行 `cargo test`、`go test ./...`、`npm test` 或 `python3 -m pytest`。

## 代码位置书签

在代码位置按 `mA` 设置 A 书签（A 到 Z 任取）；按 `` `A `` 精确跳回列，按 `'A` 跳回该行。大写书签跨文件，并随 Neovim 的 ShaDa 保存到下次启动。当前文件临时书签可用 `ma`、`` `a ``。按 `<Space>sm` 或运行 `:Bookmarks` 搜索已设书签；`:delmarks A` 删除 A 书签。
